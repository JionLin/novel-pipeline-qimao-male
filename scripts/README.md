## ⚡ 二、 快速上手与多小说运维 5 步走 (Workflow & Multi-Project Guide)

### 步骤 1：全自动构思总纲与初始化项目工作区
```bash
# 生成 270 万字（1125章）全书总纲并自动在桌面建立独立工作区沙盒
python3 scripts/auto_outline.py master "题材描述：历史架空/工业争霸/藩王就藩" 2700000
```
* **系统自动完成**：
  1. **Pass 1 + Pass 2 两段式串行生成**：Pass 1 锁定设定基座，Pass 2 展开分卷沙盘与 7 维高纯度战役工程参数卡，内存无缝拼接为 35KB 纯净总纲（彻底避开 8192 Token 截断）；
  2. 在桌面生成时间戳隔离目录（如 `大纲_270万字_1125章_.../`）；
  3. 原子化初始化生成该书私有的 `config.yaml`、`knowledge_graph.db` 和 `memory.db`；
  4. 自动将 `scripts/.active_project` 绑定至新书目录。

---

### 步骤 2：自动规划卷施工图与微观章节细纲
```bash
# 【模式 1：手动生成样本】为第 1 卷自动生成卷施工图并生成第 1~3 章高精度细纲 (或自定义 1~20 章)
python3 scripts/auto_outline.py chapters 1 3 1
```
* **系统生成机制**：
  1. **半卷双批次施工图**：自动按上半卷（块1~3）与下半卷（块4~6）串行规划《第1卷_块级施工图.md》，锁定物资血脉与苏冷霜情感阶段；
  2. **细纲两种调度模式**：
     * **手动生成**：命令行指定 `chapters 1 3 1` 生成 3 章，指定 `chapters 1 20 1` 生成 20 章；
     * **JIT 自动滑动窗口**：直接启动正文流水线（步骤 3）时，系统会在后台**自动以 3 章为滑动窗口边写边向前动态推导**，永远保持前方 3 章极品细纲储备，彻底消灭同质化假寐！

---

### 步骤 3：启动多 Agent 流水线撰写正文（一键直出即终稿）
```bash
# 批量全自动生产第 1 到第 1 章正文 (0 人工介入，一次性成稿)
python3 scripts/run_pipeline.py 1 1
```
* **单章全自动双核闭环工作流**：
  * **Planner**：查 `knowledge_graph.db` 唤醒休眠实体 + 查 `memory.db` 催收到期伏笔 + 场景派生味觉与四类休整池，编译为 0 冗余确定性填空任务书；
  * **Writer**：消费 100 字黄金 Few-Shot 正反范例，自适应控温心流撰写，执行有限视角与叙事温度句式；
  * **Reviewer**：0ms 本地代码预检 + 五道红线深度质检（支持三级阶梯自愈）；
  * **0ms 自动修剪 (In-Flight Auto-Healing)**：交付前自动修剪章末口号、平滑假寐泛滥、补齐漏写味觉；
  * **StateTracker**：增量更新并自动回写同步至 KG 与 Memory 双数据库；
  * **Publisher**：原子落盘、发布版净化、全书合集追加并重绘 `目录.md`。

---

### 步骤 4：多小说工作区秒切与活动指针绑定 (Switch Workspace)
```bash
# 方式 A：推荐命令行一键秒切（自动校验三要素、纠偏子路径并写入指针）
python3 scripts/outline/cli_wizard.py switch ~/Desktop/生成的小说/目标小说目录

# 方式 B：手动直改活动指针
echo "~/Desktop/生成的小说/目标小说目录" > scripts/.active_project
```
* **适用场景与工作机理**：
  * 当你本地同时管理多本小说时，流水线所有脚本（`run_pipeline.py`、`tools/` 看板、测试）均通过 `scripts/.active_project` 锁定当前活动工作区；
  * 切换后，系统**自动 100% 切换读取目标小说**的私有 `config.yaml`、`大纲.md`、`第X卷_章节细纲.md`、`正文/` 及 SQLite 图谱记忆库，不同小说之间 0 污染、0 串味。

---

### 步骤 5：外部独立大纲文件一键导入与沙盒建档 (Bootstrap External Master Outline)
```bash
# 将一份现成的外部 markdown 大纲文件，一键升级为具备完整数据库与配置的工业小说沙盒
python3 scripts/outline/cli_wizard.py bootstrap ~/Desktop/生成的小说/新书沙盒目录 ~/Downloads/外部大纲.md
```
* **适用场景与工作机理**：
  * **适用场景**：你手头有一份外部写好的 `大纲.md`，想直接利用流水线进行卷施工图、章节细纲规划与正文生产；
  * **系统自动完成**：
    1. 自动解析该外部 Markdown 大纲，执行 `extract_full_project_manifest` 萃取随从身体习惯、宿敌信物、灵魂物象 5 阶段里程碑与呼吸章轮换序列；
    2. 自动在新书沙盒目录生成结构化 `config.yaml`；
    3. 自动初始化 `knowledge_graph.db`（建立角色节点与物象因果）和 `memory.db`（FTS5 倒排索引）；
    4. 自动将 `scripts/.active_project` 秒切绑定至该新书目录，建档完成后可直接执行步骤 2 或步骤 3！
