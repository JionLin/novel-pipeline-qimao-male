# 题材文风（维度三）：声线分层与禁用词红线（执行级）

> **适用阶段**：L3对白规划 / L4正文主笔对白 / L5审读红线核验。


### 1. 声线分层与对白规范表

| 阶层角色 | 声线特征 | 台词示例 | 严禁表达 |
| :--- | :--- | :--- | :--- |
| **藩王/主角（对外）** | 单句短促凌厉，直刺利益命门 | “本王若想造反，第一个杀的就不是蛮子。” | 长篇大论、现代空洞煽情 |
| **藩王/主角（对内/造物）** | 语速极慢，以参数/材质为核心 | “左侧锁骨甲片多压了半厘，骑马放铳时后坐力会震裂锁骨。” | 现代纯学术术语 |
| **朝廷高官** | 慢条斯理，句句带祖制/体面/规矩 | “祖宗成法不可变，王爷此举恐伤国本。” | 市井粗口、直白下令 |
| **边将/武官** | 粗粝短促，直击粮饷与生死 | “关上还有两千张要吃饭的嘴，您拿铁皮画饼可填不饱。” | 文绉绉书生腔 |
| **工匠/老卒** | 粗鲁短句、尺寸公差、材质骂娘 | “这铁是生熟掺着打的，脆得跟豆腐渣似的。” | 文雅客套与奉承 |
| **文人/清流** | 引经据典、满口仁义道德 | “圣人治天下以德，不以奇技。北地工坊黑烟蔽日，伤天地之和。” | 利益直接摊牌 |


### 2. 声线四禁铁律（全书零容忍）

1. **主角不讲空洞煽情独白**（所有话语以利益、军权或物理公差为底层支撑）；
2. **反派不讲低幼辱骂**（严禁“小杂种/废狗/贱种/找死”等无脑台词，反派需具备成年人的利益算计）；
3. **工匠不讲文绉绉奉承**（老工匠只认技术与赏钱，台词夹杂材质与方言）；
4. **章末不讲未来时复仇口号**（严禁“定叫天下震颤/定让大周改天换地”，以物理动作与风雪留白收尾）。


### 3. 禁用词完整清单（执行级负例）

#### 3.1 现代度量衡与时间
- 公斤/千克/吨/克 ➔ 斤/石/两/钱/分
- 米/厘米/毫米 ➔ 丈/尺/寸/分/厘
- 小时/分钟/秒 ➔ 时辰/刻/炷香/盏茶/弹指
- 摄氏度/华氏度 ➔ 仅用感官白描（如“铁坯烧至樱桃红”、“炉膛泛青白”）

#### 3.2 现代火器与化工
- 子弹/弹匣/弹夹/口径 ➔ 铅弹/弹丸/定装药包/分
- 无烟火药/黑索金/TNT/硝化甘油 ➔ 全书禁用（第 1 卷严格零容忍）
- 金砂震天散/神火飞鸦等玄幻浮夸命名 ➔ 严禁使用，统一规范为工艺感名称（如“三分七厘速燃粒药”、“重工T-1式枪炮药”）
- 量子/分子/原子/能量/功率/动能 ➔ 一律用工匠口语白描替代

#### 3.3 现代军事编制与战术
- 团/旅/师/军/连/排/班 ➔ 营/协/标/镇/队
- 机枪/自动步枪 ➔ 连珠铳/重型火铳
- 地雷（非限定） ➔ 拉火雷/地火罐/埋地生铁罐
- 战壕/碉堡 ➔ 壕沟/胸墙/掩体/暗堡

#### 3.4 现代经济与政治
- 银行/信贷/预算/财政 ➔ 钱庄/账册/度支/府库
- 法律（非限定） ➔ 律/法/例/条例
- 外交使节（非限定） ➔ 使臣/钦差/信使


### 4. 情感微动作与身体语言白描词库（非战静默与微温场景专用）

| 身体部位 | 微动作形态 | 情绪与张力指向 | 具象例句规范 |
| :--- | :--- | :--- | :--- |
| **手指** | 指尖无意识捻搓某物边缘（衣角/杯沿/纸张/工具） | 焦虑/犹豫/克制/思索 | “她指尖在账本边缘捻了两下，糙纸起了一层细毛边。” |
| **手掌** | 全掌按在桌面/冰冷工具上，指关节根根发白 | 压抑情绪/下定决断 | “掌心死死压住铁尺，五根手指骨节泛白，木案上压出一道湿热掌印。” |
| **咽喉** | 喉头滚动/吞咽动作迟滞下咽 | 强忍情绪/隐忍戒备 | “他低头时喉头缓慢滚了一下，像把什么话连同冷水一起硬咽了回去。” |
| **视线** | 视线定格在某处不动，超过正常注视时长 | 失神/内心震荡/洞察 | “她盯着那张密折边缘的朱砂批注看了三息，比核算十笔旧账还久。” |
| **呼吸** | 吸气停顿/呼出白汽时肩线塌陷 | 卸力/交付信任/释怀 | “他呼出那口白汽时，紧绷了一整夜的肩膀终于沉下来半寸。” |
| **肩背** | 肩胛骨在粗布下的微缩/防备至放松 | 卸除敌意/默契协同 | “那一根筋从肩胛骨一直绷到后颈，侧身退后半步才慢慢松缓下来。” |

**白描强制规范**：
1. 微动作必须附带具体的**身体坐标与物理力学锚点**（哪只手、哪个部位、受力与位移）；
2. 微动作之后必须衔接**物理环境反馈**（如“瓷碗搁在木案上发出一声沉闷钝响”）；
3. 严禁主观心理总结（如“她感到十分悲伤”），纯靠身体物理动作完成情绪传导。
