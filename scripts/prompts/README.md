# 📜 prompts 目录：洋葱分层通用提示词中心 (Onion-Layered & Modular)

`prompts` 目录统一维护整套小说流水线中的 6 大层级系统提示词（Prompt Templates）与 **24 题材专属文风卡插件库（Genre Prose Cards）**。

整套体系全面采用 **【洋葱分层架构（80% 通用文学力学母版 + 20% 题材文风插件卡）】**，实现 **100% 零业务硬编码、全题材动态插拔、全生命周期阶段按需加载与 0ms 纯代码微创修剪**。

## 🛠️ 配合的本地算法引擎（0ms 纯代码）

1. **三遍去 AI 微创修剪引擎（`pipeline/utils.py`）**：
   - **Pass 1（段落呼吸平滑）**：合并机械单句碎段，保持 100~200 字自然段落节奏；
   - **Pass 2（八股套话置换）**：将 19 项 AI 套话（如“倒吸凉气/嘴角泛起冷笑”）无损置换为生理反应与物理动作；
   - **Pass 3（场景味觉补帧）**：自动补齐味觉描写与标点方差平滑。
2. **跨章动作与道具冷却节流器（`pipeline/context_analyzer.py`）**：
   - 自动探测连续 2 章以上的重复微动作或同一道具高频出现，动态注入“冷却警告与动作池轮换”指令。
3. **科技树分卷门禁拦截器（`agents/agent_3_reviewer.py`）**：
   - 本地 0ms 扫描当前分卷科技树白名单，发现跳代科技词汇直接熔断打回。
